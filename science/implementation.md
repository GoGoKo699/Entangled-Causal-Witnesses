# Implementation and charged resources

[Overview](README.md) · [Two-setting witness](witness.md) · [Interpretation](interpretation.md)

The mathematical law allows every integer local dimension $`d\ge2`$. The qubit implementation below realizes the family when $`d=2^n`$. It uses explicit states and circuits; no data-loading oracle or QRAM is required.

## Prepare the input

Choose $`U=Z`$ on the first qubit of register $`B`$, with identity on its other $`n-1`$ qubits. Then the attaining input factors as

```math
|\psi_{p_*}\rangle
=\left(\sqrt{p_*}|\Phi^+\rangle
+\sqrt{1-p_*}|\Phi^-\rangle\right)_{A_1B_1}
\otimes |\Phi^+\rangle^{\otimes(n-1)}.
```

The first pair is

```math
\frac{\sqrt{p_*}+\sqrt{1-p_*}}{\sqrt2}|00\rangle
+\frac{\sqrt{p_*}-\sqrt{1-p_*}}{\sqrt2}|11\rangle.
```

A one-qubit rotation followed by a CNOT prepares that real two-amplitude state, including its relative sign. The remaining pairs require the ordinary Hadamard–CNOT Bell preparation. Preparation uses $`2n`$ input qubits and $`O(n)`$ gates; with pairwise connectivity its pair operations can run in parallel. The entanglement entropy is

```math
S(\rho_B)=n-1+h_2\!\left(\frac{1+2\sqrt{p_*(1-p_*)}}2\right)
=n-O_q(1).
```

These cross-register correlations are a consumed preparation resource. If $`A,B`$ are initially held by separate laboratories, the required entanglement must be distributed or generated by an explicitly allowed interaction. Local classical shared randomness is already included in the separable benchmark.

## Realize the Bell-effect apparatus

The apparatus tests

```math
E_d=|\Phi_d\rangle\langle\Phi_d|
=\bigotimes_{j=1}^{n}|\Phi^+\rangle\langle\Phi^+|_{A_jB_j}.
```

Apply an inverse Bell-preparation Clifford to each pair. The effect $`E_d`$ is now the all-zero computational-basis test on $`2n`$ qubits.

One implementation measures these transformed input qubits ideally, evaluates the all-zero predicate classically, and retains only its truth value. A coherent alternative computes that predicate reversibly into one clean flag, measures the flag and discards the input and workspace. A standard reversible AND uses $`O(n)`$ elementary reversible gates and $`O(n)`$ clean workspace in a direct construction; a tree organization has $`O(\log n)`$ predicate depth given sufficient connectivity. Pairwise Clifford operations and this predicate evaluation are part of the apparatus cost.

The ideal binary output is then flipped by one binary symmetric channel with probability $`q`$. The resulting effects are exactly

```math
F_1=qI+(1-2q)E_d,
\qquad
F_0=(1-q)I-(1-2q)E_d.
```

Both registers enter a genuinely joint test; this is not a protocol consisting solely of local operations on $`A`$ and $`B`$. When the registers are spatially separated, transporting their states or implementing the required cross-register operations must be included in a physical realization. The mathematical claim imposes no geometry or communication-time bound on that realization.

The classical-output channel is entanglement breaking with respect to an external reference. This property does not remove the nonlocal measurement resource inside its definition.

## Measure the witness

The two settings in [the witness account](witness.md) require either no first-time measurement, or one ideal $`Z`$ measurement on the first qubit of $`B`$. The final bit is measured in both settings. The first measurement is a coarse measurement of $`U`$ on the full register: it does not resolve every computational basis string.

The number of measurement settings is two, independently of $`n`$. This does not make the cost of a run independent of $`n`$: each run consumes the input state and applies the joint apparatus. Estimating a constant witness gap at fixed $`q`$ adds a bounded number of repetitions for fixed confidence, on top of these per-run costs.

## Noise and precision boundary

The proved parameter $`q`$ describes one final reported-bit error. Internal pairwise readout, reversible gates, clean ancillas, initial entanglement and the $`U`$ measurement are ideal. The law does not describe independent detector errors on every Bell pair followed by an AND, nor imperfect state preparation or coherent gate noise. Those changes alter the channel or the available input and require a separate analysis.

The input parameter $`p_*`$ depends on the specified $`q`$. The analytic gate counts treat one-qubit rotations as available ideal operations. A fault-tolerant implementation must additionally charge synthesis precision and any calibration of $`q`$; no fault-tolerant T-count optimum is asserted here.
